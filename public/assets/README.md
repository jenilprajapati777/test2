# Replaceable Museum Media Assets

Drop your real files into these folders to replace the placeholders without touching any code:

- `public/assets/photos/` : Place `P1.jpg`, `P2.png`, etc. (supports .jpg, .jpeg, .png, .webp, .svg)
- `public/assets/videos/` : Place `V1.mp4`, `V2.mp4` (supports .mp4, .webm)
- `public/assets/audio/`  : Place `ambient.mp3`, `click.mp3`, etc.
- `public/assets/characters/` : Optional GLTF/GLB models for Jenil and Rutu (`jenil.glb`, `rutu.glb`)
